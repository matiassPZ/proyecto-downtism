# Proyecto Downtism

Proyecto educativo interactivo diseñado para brindar un espacio didáctico, inclusivo y entretenido mediante juegos, dibujos y música.

## 📁 Contenido del Proyecto

- **`DOWNTISM.html`**: Página principal del proyecto.
- **`Juegos/`**: Minijuegos interactivos:
  - `(juego 1) Laberinto relajante.html`
  - `(juego 2) Armando figuras coloridas.html`
  - `(juego 3) Completa la línea de números.html`
- **`Imágenes/`**: Ilustraciones, logotipos y recursos gráficos utilizados en la plataforma.
- **`Música/`**: Pistas de audio relajantes que acompañan la experiencia.
- **`Exposición del proyecto (feria) 6to C.pptx`**: Presentación para la feria de proyectos.
- **`carpeta de proyectos ejemplos/`**: Documentación de apoyo y referencias.

## 🚀 Cómo ejecutarlo

Para probar la plataforma localmente:
1. Clona o descarga este repositorio.
2. Abre el archivo `DOWNTISM.html` en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, etc.).
